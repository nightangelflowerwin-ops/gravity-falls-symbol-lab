# Global glyph source pass

Collected a reproducible Unicode 18.0.0 character database snapshot on 2026 10 05, containing UnicodeData.txt, Scripts.txt, Blocks.txt, ReadMe.txt and the license. The archive includes a SHA256 source manifest. The generated catalog counts 172,873 public assigned characters across 175 scripts plus Common and Inherited. Private use and surrogate code points are excluded. Sixteen algorithmic ranges remain compact; 41,297 explicit character records are searchable separately.

This is a character source inventory, not a collection of every drawn glyph or proof of language. Different fonts, historical hands, ligatures, bindrunes, cipher variants and invented alphabets can exceed the encoded inventory. Common and Inherited script properties are not language names. Rendered examples depend on local font coverage and missing font boxes must never be compared as glyphs.

Seventeen additional leads cover historical alphabets, geometric ciphers, manuscript collections, fictional systems and symbols. Primary or institutional witnesses are prioritized. Discovery indexes are labeled as leads. No additional identity is accepted for the final border mark or tablet graphics. Current automated comparison coverage remains 137 reference forms.
