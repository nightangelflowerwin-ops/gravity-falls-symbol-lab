How the translator works and where the keys come from

Local contrast separates dark strokes from the background. Column projection separates glyphs; wide groups are split by comparing candidate shapes. Normalized glyphs are matched against image templates. There is no cloud upload, API key, language model, or wallet interaction.

The English alphabet has 26 chart-derived entries plus examples from the supplied image. Russian entries are derived from published readings of this specific image, checked for repeated shapes. This is a partial custom Cyrillic alphabet, not an official Russian Gravity Falls key. Missing letters and the final right-edge symbol remain unresolved.

Spacing is preserved as separators or image gaps. Russian translation uses exact phrase matches and a small word dictionary; unseen sentences remain literal word glosses. Results are not forced to match the expected text.

Works offline as a standalone HTML file. Uploaded images and added templates stay in this tab; use Export to save results. Controls and corrections never alter the source image.
