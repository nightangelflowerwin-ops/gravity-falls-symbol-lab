# Dictionary updates

Every research addition belongs in the Gravity Falls dictionary dashboard and repository. Integrate source notes, extracted text, comparisons, evidence and downloadable files into the offline application. Update the source data, rebuild index.html, run the relevant browser checks, and publish the tested update.

Preserve exact source strings and unknown positions. Label provisional transcriptions, annotations, comparison normalizations and verified source matches separately. Do not infer glyph identities from resemblance alone.

Titles have no hyphens. Application source and tests have no explanatory code comments. Preserve functional directives and required license notices.
